# APK REPONSI

## Deskripsi Aplikasi
APK REPONSI adalah template aplikasi CRUD berbasis
Command Line Interface (CLI) menggunakan Python.
Aplikasi ini dibuat untuk memenuhi kebutuhan tugas praktikum.

## Fitur
- Create
- Read
- Update
- Delete
- Validasi input

## User Guide
1. Jalankan program dengan python apkreponsi.py
2. Gunakan menu untuk mengelola data
3. Pilih Exit untuk keluar dari program
